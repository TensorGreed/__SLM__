# BrewSLM Demo Workspace

This workspace is for evidence-backed demos, slide planning, browser recordings, and narration for the TensorGreed/__SLM__ repo.

Ground rules:
- The only official demo sample folders are `backend/data/demo_samples/pii-detector`, `backend/data/demo_samples/sentiment-classifier`, and `backend/data/demo_samples/support-faq`.
- Demo claims must cite repo evidence before they appear in slides, narration, or Playwright flows.
- Real recording scripts come after pipeline discovery. The first Playwright spec is only a browser-recording smoke test.

Start here:
- Evidence: `docs-demo/evidence/`
- Learning path: `docs-demo/learning-path/`
- Video plans: `docs-demo/videos/`
- Agent instructions: `docs-demo/agents/`
