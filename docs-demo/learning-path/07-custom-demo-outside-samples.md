# Custom Demo Outside Samples

Status: conceptual/partial.

A custom demo should not be presented as an official template. It should begin with "bring your own dataset" and use verified repo import paths.

Possible path:
1. Upload or remote-import a dataset.
2. Inspect raw rows.
3. Clean data.
4. Create/import gold examples.
5. Generate synthetic examples if runtime is configured.
6. Prepare train/validation/test splits.
7. Configure training.
8. Evaluate.
9. Export or serve.

Evidence needed:
- Import wizard selector map.
- A small custom CSV.
- Cleaning results.
- Gold import/create path.
- Runtime mode for synthetic/training/export.
