# Demo Quality Rules

- No fake features.
- No unsupported claims.
- No generic ML demo assumptions unless marked conceptual.
- Every demo slide should have evidence.
- Every browser demo should be repeatable.
- Every video should have a goal, audience level, prerequisites, UI path, narration, and evidence.
- Mark simulated paths clearly.
- Mark heavy runtime requirements clearly.
- Prefer beginner-friendly explanation first, then technical depth.
- Real UI recording scripts must come after pipeline discovery, not before.
