Where Things Run

All on the box. No cloud.

GPU work

  • Training: PyTorch + transformers + PEFT
  • Inference: Ollama (llama.cpp under the hood)
  • Eval generation: same GPU, bf16
  • Quantization: llama.cpp/quantize

CPU + disk

  • DB: data/slm_platform.db
  • Project artifacts: data/projects/<id>/
  • Exports: data/exports/<id>/
  • Ollama models: ~/.ollama/models/
