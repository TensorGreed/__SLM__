# Video Series Plan

## Series Goals

- Teach SLM basics to a beginner.
- Show what BrewSLM appears to provide from repo evidence.
- Record real UI/API paths only after pipeline discovery.
- Keep every claim labeled as verified, partial, simulated, estimated, conceptual, or unknown.

## Modules

| Video | Working title | Audience | Status | Evidence dependency |
|---|---|---|---|---|
| 01 | SLM 101 | beginner | conceptual | General ML concept only; no product claims. |
| 02 | BrewSLM Quickstart | beginner | partial | Demo tiles, login, project routes, demo seeder. |
| 03 | Support FAQ Pipeline | beginner/intermediate | partial | `support-faq` sample and seeded project behavior. |
| 04 | PII Detector Pipeline | intermediate | partial | `pii-detector` manifest, span schema, generator/converter scripts. |
| 05 | Sentiment Classifier Pipeline | beginner/intermediate | partial | `sentiment-classifier` manifest and CSV/gold labels. |
| 06 | Custom Outside Samples Pipeline | intermediate | conceptual/partial | Dataset import, cleaning, synthetic, dataset prep, training APIs need run-through. |
| 07 | Final Model Usage | intermediate | unknown/partial | Playground, export serve runs, registry, deployment APIs need run-through. |

## Recording Order

1. Run the prototype Playwright smoke test.
2. Record a manual discovery pass with notes, not a polished demo.
3. Create one real sample recording after selectors and API states are documented.
4. Only then scale to the three official sample recordings.
